## 🔓 Open-source contributions

A couple of projects I've worked on as part of my professional work at ioki. My contributions were made using my work GitHub account, **[@tom-ioki](https://github.com/tom-ioki)**.

### [ioki-ruby](https://github.com/ioki-mobility/ioki-ruby)
Ruby client library for ioki APIs. Provides a convenient interface for interacting with the different ioki APIs and working with their responses as Ruby objects.

### [tickeos_b2b](https://github.com/ioki-mobility/tickeos_b2b)
An in-house developed Ruby gem for the TICKeos B2B API. Provides Ruby bindings for ticket retrieval, product information and ticket purchases.
